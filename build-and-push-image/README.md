# build-and-push-image

<!-- AUTO-DOC-DESCRIPTION:START - Do not remove or modify this section -->

Build and push the image.

Optionally also update the 'latest' image tag.


<!-- AUTO-DOC-DESCRIPTION:END -->

## Inputs

<!-- AUTO-DOC-INPUT:START - Do not remove or modify this section -->

|      INPUT      | REQUIRED |   DEFAULT    |                                                                                                                                                                                                                                                                                                                 DESCRIPTION                                                                                                                                                                                                                                                                                                                 |
|-----------------|----------|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  baseImageName  |   true   |              |                                                                                                                                                                                                                                                                                   Base name of the image, without <br>a tag, such as 'ideacrew/enroll'.                                                                                                                                                                                                                                                                                     |
|   dockerFile    |   true   |              |                                                                                                                                                                                                                                                                                             Path to the docker build file <br>in the project.                                                                                                                                                                                                                                                                                               |
|  dockerTarget   |  false   |  `"deploy"`  |                                                                                                                                                                                                                                                                                                      Name of the target docker stage.                                                                                                                                                                                                                                                                                                       |
|  ghcrPassword   |   true   |              |                                                                                                                                                                                                                                                                                                             Password for GHCR.                                                                                                                                                                                                                                                                                                              |
|  ghcrUserName   |   true   |              |                                                                                                                                                                                                                                                                                                             Username for GHCR.                                                                                                                                                                                                                                                                                                              |
| lastUpdateStamp |  false   | `"20251021"` | A text tag used for cache <br>busting when fetching updates for the <br>docker image. It's passed as a <br>docker build argument, usually of the <br>form YYYYMMDD. This can be used <br>to explicitly track, in the repository <br>using the action, the last time <br>the image had security updates run <br>during the build process. It's injected <br>into the image as the `LAST_IMAGE_UPDATE_BUMP` <br>build argument. It's up to the <br>**developer** to make use of this <br>variable in the Docker file to <br>bust the cache. Right now it <br>defaults to the last time someone <br>set the default in the github <br>action.  |
|    loadImage    |   true   |              |                                                                                                                                                                                                                                                                                                         Should the image be loaded?                                                                                                                                                                                                                                                                                                         |
|    pushImage    |   true   |              |                                                                                                                                                                                                                                                                                                         Should the image be pushed?                                                                                                                                                                                                                                                                                                         |
|   pushLatest    |  false   |  `"false"`   |                                                                                                                                                                                                                                                                                             Should we also update the latest <br>docker image?                                                                                                                                                                                                                                                                                              |
|  registryGhcr   |  false   | `"ghcr.io"`  |                                                                                                                                                                                                                                                                                                       The GCHR registry for uploads.                                                                                                                                                                                                                                                                                                        |
|     tagName     |   true   |              |                                                                                                                                                                                                                                                                      Tag suffix to apply to the <br>end of the image name, usually <br>'\<branch-name>-\<short sha>'.                                                                                                                                                                                                                                                                       |
